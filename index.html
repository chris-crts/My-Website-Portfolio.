CASE FILE 02
COMPLETED
HealthTech • AI

AI-Powered Clinical Management System

Semantic Search · RAG Chatbot · Medicine Recommendation · Electronic Health Records

OBJECTIVE Developed an intelligent clinical management system that streamlines appointment scheduling, electronic health records, and medicine inventory while assisting healthcare professionals through AI-powered semantic retrieval and contextual clinical decision support.
SEMANTIC AI ENGINE Leveraged BioBERT to transform patient symptoms, medical history, and medicine knowledge into semantic vector embeddings. Indexed embeddings using Annoy (Approximate Nearest Neighbor) to enable high-speed similarity search, context-aware medicine retrieval, and explainable recommendation scoring.
RAG MEDICAL ASSISTANT Designed a Retrieval-Augmented Generation (RAG) chatbot that combines semantic retrieval with BioGPT to answer patient-specific medical questions, explain medicine recommendations, summarize health records, and generate contextual responses using retrieved clinical information instead of relying solely on a language model.
Django Python PostgreSQL BioBERT BioGPT Semantic Embeddings Annoy Index RAG Vector Search REST API RBAC HTML / CSS / JS
